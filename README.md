# Omega IPA Repo

Self-hosted AltStore/SideStore source.

- `apps.json` — the source manifest (edit to add your IPAs)
- Host each `.ipa` in this repo's **Releases**, put its URL in `downloadURL`
- Enable **GitHub Pages** (Settings - Pages - Source: Deploy from branch, `main` / root)
- Add source URL in AltStore/SideStore: `https://ElProfessorFRidg.github.io/omega-ipa/apps.json`
